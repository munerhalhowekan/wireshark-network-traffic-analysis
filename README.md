# Wireshark Network Traffic Analysis

## Overview
Hands-on network security lab focused on capturing and analyzing
TCP and ICMP traffic using Wireshark.

## Tools & Technologies
- Wireshark
- TCP/IP
- ICMP
- PCAP Analysis
- Ping / Command Line

## Part 1 — TCP Traffic Capture
- Captured TCP traffic generated during a file transfer.
- Saved captured network traffic as a PCAP file.
- Identified client and server IP addresses.
- Identified source and destination TCP ports.

## Part 2 — TCP Connection Analysis
- Analyzed the TCP three-way handshake.
- Identified SYN and SYN-ACK packets.
- Examined TCP sequence numbers.
- Identified the first TCP segment containing application data.

## Part 3 — ICMP Traffic Analysis
- Generated ICMP traffic using the ping command.
- Captured ICMP Echo Request and Echo Reply packets.
- Examined source and destination IP addresses.
- Analyzed fields used to associate ICMP requests with their responses.
